# moro-demo-page

صفحة ويب تجريبية بسيطة بملف واحد — بناها MORO (المساعد الشخصي للمهندس سامر).

## المحتوى

- `index.html` — الصفحة كاملة (HTML + CSS + JS بدون أي مكتبات خارجية)

## الميزات

- تصميم عربي بالاتجاه من اليمين إلى اليسار (RTL)
- عدّاد تفاعلي (زيادة / إنقاص / تصفير)
- تبديل ثيم ليلي/نهاري مع حفظ الاختيار في `localStorage`
- ساعة حيّة تُحدَّث كل ثانية
- تخطيط متجاوب يتكيف مع الجوال والحاسوب

## التشغيل محلياً

```bash
python3 -m http.server 8080
```

ثم افتح: http://localhost:8080

أو افتح ملف `index.html` مباشرة في المتصفح.
