# تعديل المنيو من الهاتف — دليل صاحب المطعم

كل شي بالمنيو موجود بملف واحد اسمه `menu-data.js`.
ما بتحتاج برنامج ولا كمبيوتر. من الهاتف، تفتح الملف، تبدّل الكلمة أو الرقم، وتحفظ. التغيير يظهر على المنيو خلال دقيقة.

## تغيير سعر
لاقي الصنف وبدّل الرقم بعد `price:`

```
{ n:'شاورما عربي', d:'خبز عربي، دجاج مشوي، ثومية، مخلل', price:2.50, i:'🌯' },
```
صار سعرها ٢.٧٥؟ خلّيها `price:2.75`. وبس.

## عمل عرض أو خصم على صنف
أضف `was:` وفيها السعر القديم:

```
{ n:'شاورما عربي', d:'...', price:2.00, was:2.50, i:'🌯' },
```
المنيو تلقائياً:
- يشطب السعر القديم ويكتب الجديد
- يحطّ شارة **عرض** حمراء على الصنف
- يعلّم الصنف بإطار أحمر
- يحسب للزبون **كم وفّر** بالسلة، ويكتبها برسالة الواتساب

لإلغاء العرض: احذف `was:2.50` فقط.

## بانر العرض أعلى الصفحة
```
promoBanner: 'عرض اليوم: شاورما عربي بـ ٢.٠٠ بدل ٢.٥٠',
```
خليها فاضية `promoBanner: '',` لتختفي.

## قسم "العروض" الكامل
أول قسم بالمنيو اسمه **العروض** وبيطلع أول شي بعين الزبون.
حط فيه الأصناف اللي عليها خصم، أو وجبات وعروض خاصة (وجبة عائلية، كومبو).
ما عندك عروض هذا الأسبوع؟ احذف القسم كله أو خلّيه فاضي.

## إخفاء صنف مؤقتاً (خلص من المطبخ)
أضف `off:true`:
```
{ n:'ريش غنم', d:'...', price:11.50, i:'🍖', off:true },
```
يختفي من المنيو فوراً بلا ما تحذف بياناته. شيل `off:true` لما يرجع.

## إضافة صنف جديد
انسخ سطر صنف موجود، ولزّقه تحته، وبدّل الاسم والوصف والسعر.

## أشياء ثانية تقدر تبدّلها
| السطر | شو يعمل |
|---|---|
| `name` | اسم المطعم |
| `tagline` | السطر الصغير تحت الاسم |
| `address` / `hours` | العنوان وأوقات العمل |
| `isOpen: true` | خلّيها `false` لتظهر «مغلق الآن» |
| `whatsapp` / `phone` | أرقامك (بلا + وبلا أصفار: 962790000000) |
| `delivery` | سعر التوصيل |
| `demoNote` | خليها `''` لتختفي جملة «نموذج توضيحي» |

## قاعدة واحدة مهمة
لا تحذف الفواصل `,` ولا الأقواس `{ }` ولا علامات التنصيص `' '`.
بدّل **اللي بينها** فقط. لو صار خطأ، رجّع اللي كان مكتوب أو اتصل فينا ونصلّحها بدقيقة.
